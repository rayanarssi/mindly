# 🧠 Mindly

**A digital wellbeing platform built with React and Vite, designed to help students and young adults manage stress, focus, and motivation.**
This project explores dynamic UI components, authentication flows and Supabase backend integration.

---

## 📌 Project Overview

This React + Vite app is part of a front-end development series focused on building modern, interactive web interfaces using best practices like modular components, state management, Supabase integration, and real-time updates.

---

## 🔑 Key Features

- ✅ Vite-powered React setup for fast development
- ✅ User authentication (login/register) with Supabase
- ✅ Dynamic forum and video resources
- ✅ Admin panel for content management
- ✅ Like/unlike and favorite system for videos
- ✅ Community/Forum to ask questions

---

## ⚙️ Setup Instructions

### 1. Clone the repository

git clone https://github.com/rayanarssi/mindly.git

## 2. Navigate into the project folder

cd mindly

## 3. Install dependencies

npm install

## 4. Start the development server

npm run dev

## 5. Build for production

npm run build

---

## 🛠️ Dev Notes & Commands

# Vite Init

- npm create vite@latest
- Choose React

# Supabase Setup

- Configure `.env` with your Supabase URL and anon key
- Tables: profiles, videos, posts, videos_favorites, reports, replies, checkins, likes, levels

# Deployment

- npm run build
- Deploy the `dist/` folder to your preferred hosting
